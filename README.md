# tsang-research.github.io
Personal academic profile for Ka Wing, built with Jekyll and the Minimal Mistakes remote theme.

## Files

- `_config.yml` controls the Jekyll theme, title, description, plugins, footer links, and Google Analytics.
- `index.md` contains the single-page profile content.
- `assets/css/main.scss` loads the default Minimal Mistakes theme.
- `assets/images/headshot.svg` is a temporary headshot placeholder.
- `assets/images/pillar-*.svg` are temporary clickable feature-row placeholders.
- `assets/cv.pdf` should be added before publishing the Download CV button.

## Before Publishing

Replace the placeholder contact links, paper links, paper titles, and `assets/cv.pdf`. The placeholders are marked in `_config.yml` and `index.md`.
